# 기성 노트 정리 방식과 AI 기반 위키 시스템의 지식 관리 효율성 비교 (2026 서전고 교내 학술제)

본 저장소는 2026학년도 서전고등학교 교내 학술제(정보 분과) 연구인 **「기성 노트 정리 방식과 AI 기반 위키 시스템의 지식 관리 효율성 비교」**의 재현성과 검증 투명성을 위해 공개한 **벤치마크 스크립트·엔진 패치·평가 문항·원시 실험 로그 아카이브**입니다.

---

## 📌 연구 및 시스템 개요

* **핵심 설계:** Andrej Karpathy의 **3계층 LLM Wiki 패턴**(`raw/` 불변 원본 – `wiki/` 마크다운 컴파일층 – `Schema` 규칙층)에 로컬 CPU 기반 **`google/embeddinggemma-2` (768차원)** 임베딩과 **True RRF 하이브리드 검색**을 결합한 AI 위키 시스템(서재 B, 활성 79개 문서·1,354개 청크)을 구현하고, 비정형 원본 폴더(서재 A, 89개 파일 455,063자)와 비교 검증했습니다.
* **비교 기준선:** 전통적 어휘 일치 검색(**BM25**) 및 전용 검색 도구 없이 디렉터리 목록·파일 본문 열람 도구만 부여받은 AI 에이전트(**Agent A**)와 위키 전용 MCP 도구를 사용하는 AI 에이전트(**Agent B**)를 동일 조건에서 비교했습니다.
* **구동 환경:** AMD Ryzen 7 250 (8코어 16스레드), 32GB RAM, Windows / 로컬 CPU 임베딩(`google/embeddinggemma-2`) / 에이전트 실험은 Antigravity 통합 실행 환경에서 `Gemini 4 Hydrogen (High)` 모델로 독립 서브에이전트를 격리 구동하여 수행했습니다.
